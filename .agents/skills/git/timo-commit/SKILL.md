# Timo 커밋

1. [팀 규칙](../../../../docs/rules.md)의 커밋 항목, 현재 브랜치, `git status`, diff를 확인한다. 브랜치의 `#번호`에 연결된 이슈를 확인한다.
2. 현재 요청과 관계없는 변경을 구분하고 커밋할 파일을 명시적으로 선택한다. 사용자가 만든 기존 변경을 임의로 포함하거나 되돌리지 않는다.
3. `git diff --check`를 실행한다. Java 변경에는 `./gradlew build`를 실행한다. 실패 원인을 해결하지 못했다면 성공한 커밋으로 제출하지 않는다.
4. 파일 경로를 명시해 스테이징하고 staged diff와 `git diff --cached --check`를 다시 확인한다. 논리적 변경 단위로 `[#번호] type(scope): 한국어 요약` 형식의 커밋을 만든다. scope가 의미 없으면 생략한다.
5. 최종 커밋 해시, 포함 파일, 검증 결과를 보고한다. 이 스킬은 푸시나 PR 생성까지 자동으로 진행하지 않는다. 함께 요청받았다면 이어서 `timo-pr`을 사용한다.
